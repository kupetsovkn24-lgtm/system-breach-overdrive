# System Breach: Overdrive — Release Checklist

## 1) Підготовка контенту

- [ ] Додано стартову сцену в **Build Settings** та увімкнено прапорець `Enabled`.
- [ ] Перевірено, що старт із `Play` коректно показує стартовий екран.
- [ ] Перевірено всі 5 рівнів (прохід + поразка + рестарт).

## 2) Налаштування гри

- [ ] Перевірено `SETTINGS` у стартовому екрані та в ігровому меню.
- [ ] Параметр гучності зберігається між перезапусками.
- [ ] Параметр якості графіки зберігається між перезапусками.

## 3) UX та керування

- [ ] `LMB` обертає тільки незаблоковані вузли.
- [ ] `R` робить швидкий рестарт рівня.
- [ ] `Esc` відкриває/закриває меню або закриває `SETTINGS`.
- [ ] Пауза зупиняє таймер і взаємодію з сіткою.

## 4) Збірка Windows

- [ ] У Unity обрано меню `System Breach/Build/Windows Release`.
- [ ] Після збірки існує файл `Build/Windows/SystemBreachOverdrive.exe`.
- [ ] Запуск `.exe` проходить без помилок і відображає стартовий екран.

## 5) Мінімальний smoke-test релізу

- [ ] Нова гра проходиться до кінця без зависань.
- [ ] `Continue` працює після перезапуску додатка.
- [ ] `Reset Progress` повертає гру до початкового стану.
- [ ] Звук ротації/перемоги/поразки відтворюється.
- [ ] Візуальні ефекти (scanlines + flash) працюють коректно.
