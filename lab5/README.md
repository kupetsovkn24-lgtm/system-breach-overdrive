# Звіт до лабораторної роботи 5

## 1. Титульна частина

- Назва дисципліни: `Геймдизайн та програмування ігрових застосунків`
- Тема лабораторної роботи: `Розширення ігрового прототипу до демонстраційної версії`
- Назва проєкту: `System Breach: Overdrive`
- Виконали: `Гарлінський Кирило, Купець Олексій, Чубок Богдан`
- Група: `КН-3/1`
- Дата виконання: `18.05.2026`

## 2. Тема роботи

Доопрацювання Unity-прототипу гри `System Breach: Overdrive` до демонстраційної версії через покращення головного меню, навігації між рівнями, HUD та базових вікон станів гри.

## 3. Мета роботи

Розширити створений раніше прототип без зміни основної ігрової механіки: зберегти логічну гру з обертанням вузлів мережі, додати зручну навігацію рівнями, відображення поточного стану проходження та завершити базовий набір UI-екранів для demo-версії.

## 4. Опис доопрацьованого прототипу

У прототипі вже була реалізована 2D puzzle-гра, де гравець обертає вузли цифрової мережі та має з'єднати джерело сигналу з усіма виходами до завершення таймера.

У межах лабораторної роботи 5 прототип доопрацьовано точково:

- залишено основний ігровий цикл без змін;
- збережено систему прогресивних рівнів;
- додано окремий екран вибору рівня `LEVEL SELECT`;
- заблоковано вибір рівнів, які ще не відкриті проходженням;
- розширено HUD показниками `MOVES` та `TOTAL SCORE`;
- додано кнопку `EXIT` у головне меню та pause menu;
- оновлено навігацію між стартовим екраном, вибором рівня, ігровим процесом, pause menu та result screen.

## 5. Опис системи рівнів

У грі використовується система з 20 рівнів. Рівні формуються через конфігурацію `LevelConfig`, а також підтримують завантаження через `LevelDefinitionSO` і `LevelDatabaseSO`.

Основні параметри рівнів:

- розмір сітки;
- час проходження;
- дозвіл на T-подібні вузли;
- кількість заблокованих вузлів;
- seed генерації;
- кількість виходів;
- кількість обов'язкових вузлів;
- кількість перевантажених вузлів;
- штраф часу за перевантажений вузол;
- поріг швидкого проходження для combo-бонусу.

Після завершення рівня відкривається наступний рівень. Гравець може продовжити з останнього відкритого рівня або вибрати будь-який уже відкритий рівень через `LEVEL SELECT`.

## 6. Перелік реалізованих елементів

### 6.1. Ігровий рівень

Доопрацьовано наявний рівневий прототип:

- джерело сигналу;
- один або декілька виходів;
- звичайні вузли мережі;
- заблоковані вузли;
- обов'язкові вузли;
- перевантажені вузли зі штрафом часу;
- різні типи з'єднань: прямий, кутовий, T-подібний і перехресний вузол.

### 6.2. HUD

У HUD відображаються:

- номер поточного рівня;
- таймер `SYSTEM HEALTH`;
- статус гри;
- прогрес цільових вузлів `OBJECTIVE NODES`;
- стан Object Pool;
- кількість ходів `MOVES`;
- загальний рахунок `TOTAL SCORE`.

HUD оновлюється під час старту рівня, обертання вузлів, зміни прогресу цілей, завершення рівня та поразки.

### 6.3. Головне меню

Головний стартовий екран містить:

- `CONTINUE`;
- `NEW GAME`;
- `LEVEL SELECT`;
- `RESET PROGRESS`;
- `SETTINGS`;
- `RULES`;
- `EXIT`.

Кнопка `CONTINUE` доступна лише якщо вже відкрито прогрес проходження.

### 6.4. Вибір рівня

Додано окремий UI-екран `LEVEL SELECT`:

- відображає 20 кнопок рівнів;
- відкриті рівні доступні для запуску;
- закриті рівні показуються як `LOCKED`;
- є кнопка `BACK` для повернення до головного меню.

### 6.5. Вікна станів гри

У прототипі реалізовано:

- pause menu з кнопками `RESUME`, `MAIN MENU`, `SETTINGS`, `RULES`, `EXIT`;
- result screen після перемоги або поразки;
- retry після поразки або завершення рівня;
- next level після успішного проходження;
- settings screen для гучності;
- rules screen з правилами гри.

### 6.6. Переходи між UI-екранами

Налаштовано переходи:

- головне меню -> нова гра;
- головне меню -> продовження;
- головне меню -> вибір рівня;
- вибір рівня -> запуск відкритого рівня;
- вибір рівня -> головне меню;
- ігровий процес -> pause menu;
- pause menu -> продовження гри;
- pause menu -> головне меню;
- result screen -> retry;
- result screen -> next level.

### 6.7. Базові анімації та ефекти

У демонстраційній версії використовуються:

- pulse-ефект сигналу після правильного з'єднання;
- flash-ефект при перемозі, поразці та перевантаженні вузла;
- стандартні transition-стани кнопок Unity UI;
- scanline overlay для стилізації інтерфейсу.

## 10. Висновок

У межах лабораторної роботи 5 прототип `System Breach: Overdrive` було доопрацьовано до демонстраційної версії. Основна механіка залишилася незмінною: гравець обертає вузли мережі та будує шлях сигналу до цільових вузлів.

Додано зручні UI-екрани для запуску гри, вибору відкритого рівня, паузи, перегляду правил, налаштувань і результатів проходження. HUD доповнено показниками кількості ходів і загального рахунку. Система рівнів підтримує прогрес проходження, перехід до наступного рівня, повторне проходження та повернення до головного меню.

Подальшого вдосконалення можуть потребувати окремі сценові асети, додаткові анімації та повноцінні відеодемонстрації, але для базової demo-версії лабораторної роботи реалізованих змін достатньо.
