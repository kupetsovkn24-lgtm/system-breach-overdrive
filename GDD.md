## 1. Високорівневий концепт ігрового застосунку

Гравець — системний адміністратор у мегакорпорації майбутнього. Ваше завдання — стабілізувати критичні вузли мережі, що піддаються хакерській атаці або системним збоям. Ви маніпулюєте блоками даних на сітці, щоб відновити зв'язки до того, як таймер "Критичної помилки" досягне нуля.

## 2. Цільова аудиторія

- Шанувальники класичних пазлів типу Pipe Mania або Tetris.
- Гравці, які люблять естетику кіберпанку та технічний сетинг.
- Користувачі, що шукають короткі, але інтенсивні ігрові сесії (casual & mid-core).

## 3. Опис ігрового світу (Сетинг)

Дія розгортається всередині віртуального термінала "Core-OS". Візуалізація нагадує цифровий простір: неонові лінії, мерехтливі символи та глітч-ефекти. Світ відчувається як "живе" залізо, де кожна секунда зволікання загрожує повним видаленням даних

## 4. Основні ігрові механіки

Основні механіки гри:

- Grid System — ігрове поле у вигляді двовимірної сітки вузлів.
- Node Rotation — обертання вузлів для створення правильного маршруту сигналу.
- Signal System — перевірка з’єднання між джерелом та кінцевим
  вузлом.
- Timer System — обмеження часу для проходження рівня.
- Level Progression — поступове ускладнення рівнів.

Ігровий процес базується на маніпуляції вузлами цифрової мережі у віртуальному середовищі Core-OS Terminal Interface.

### Grid System

Ігрове поле представляє собою двовимірну сітку (Grid), стилізовану під інтерфейс мережевого терміналу. Кожна клітинка містить фрагмент мережевого вузла.
| Тип вузла | Опис |
|----------------|------|
| Straight Node | прямий канал передачі сигналу |
| Corner Node | кутовий сегмент |
| T Node | вузол з розгалуженням |
| Locked Node | вузол, який не можна обертати |

### Rotation Mechanic

Гравець взаємодіє з вузлами за допомогою миші.
**LMB** → обертання вузла на **90°**.
Мета гравця — створити \*\*безперервний шлях сигналу\*\* від джерела до виходу.

### Signal System

Після побудови правильного ланцюга сигнал проходить через мережу.
Це супроводжується:

- підсвічуванням активного шляху
- короткою анімацією проходження сигналу
  Якщо сигнал досягає кінцевого вузла — **рівень вважається завершеним**.

### Critical Error Timer

Кожен рівень має \*\*таймер стабільності системи (System Health)\*\*.
Правила:

- таймер поступово зменшується
- якщо час закінчується — відбувається System Failure
- рівень перезапускається

## 5. Основний ігровий цикл (Core Loop)

Гра має простий повторюваний цикл для кожного рівня:

### Ініціалізація

Генерується сітка вузлів з перемішаним правильним шляхом.

### Старт рівня

Запускається таймер стабільності системи.

### Дія гравця

Гравець аналізує розташування вузлів та обертає їх для створення правильного маршруту сигналу.

### Перевірка

Система перевіряє цілісність ланцюга після кожної дії.

### Результат

- Перемога: сигнал досягає виходу → таймер зупиняється → показується повідомлення System Restored → завантажується наступний рівень.
- Поразка: таймер досягає нуля → показується повідомлення System Failure → рівень перезапускається.

## 6. Система прогресії

Для спрощення розробки використовується **набір фіксованих рівнів** з поступовим ускладненням.

| Рівень | Сітка | Таймер | Особливості                   |
| ------ | ----- | ------ | ----------------------------- |
| 1      | 3х3   | 60 сек | Навчальний рівень             |
| 2-3    | 4x4   | 45 сек | додаються T-вузли             |
| 4-5    | 5х5   | 40 сек | з’являються заблоковані вузли |

## 7. Візуальний стиль

Візуальний стиль гри базується на концепції **UI-driven cyberpunk terminal interface**.
Гра виглядає як робота всередині віртуального терміналу **Core-OS**.

### Основні елементи стилю

**Фон**:

- чорний або темно-синій
- стилізація під цифрове середовище

**Активні з’єднання**:

- неоновий блакитний (Cyan)

**Помилки**

- яскравий червоний або пурпуровий

**Візуальні ефекти**
Для створення атмосфери цифрового простору використовуються:

- Bloom (неонове світіння)
- Scanlines (ефект старого монітора)
- легкий Chromatic Aberration
- прості glitch-ефекти

## 8. Користувацький інтерфейс і керування

### Керування

- LMB — обертання вузла
- R — швидкий рестарт рівня

### HUD

Інтерфейс складається з трьох основних частин:

- Центральна область: ігрове поле (Grid);
- Верхня панель: таймер / індикатор стабільності системи;
- Кнопки навігації: Pause, Restart, Menu.

## 9. Готовність до програмної реалізації

Гра реалізується у **Unity (2D)** з використанням простих систем.

### Основні модулі:

| Система       | Призначення             |
| ------------- | ----------------------- |
| Grid Manager  | створення ігрового поля |
| Node System   | керування вузлами       |
| Input System  | обробка кліків гравця   |
| Signal System | перевірка з’єднання     |
| Timer System  | керування таймером      |
| Level Manager | завантаження рівнів     |
